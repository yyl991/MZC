## 🚨 2. 绝对避坑指南（违者必崩）

### 2.1 全局返回键系统（已高度封装）
- **逻辑**：`app.js` 的 `show()` 中有一个 `ROOT_VIEWS` 白名单。
- **一级页面（App 主界面）**：在白名单中，**绝对不注入**返回键。
- **二级页面**：如果没有 `.nav` 或 `.wx-chat-h` 容器，系统会自动在绝对定位（`top:45px; left:10px`）注入一个悬浮纯箭头返回键。
- **警告**：业务代码里**不要再手写大段绝对定位的返回键**，防止出现双重返回键或样式冲突。

### 2.2 黑胶唱片动画（`home_ui.js`）
- **绝对禁止使用 CSS 动画**。必须用 JS 的 `requestAnimationFrame` 实时计算角度并赋值 `style.transform`。
- 收到微信消息引发重绘时，必须加 `window.isVinylBusy` 锁，防止打断唱片旋转。

### 2.3 音频调度（`core/audio.js`）
- BGM 被打断只能 `pause()`，**绝对不能碰 currentTime = 0**。
- `AudioHub` 已全局接管 `<video>` 和 `<audio>` 的播放拦截，**不需要手写暂停 BGM 代码**。

### 2.4 UI 冻结
- 除非用户要求，否则不要改动现有的 DOM 结构、class 名和布局参数。遇到 UI 问题，先考虑局部 margin/padding 调整。
