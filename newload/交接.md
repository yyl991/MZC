# 📱 核心项目交接文档：《橙粉色捡起来》iPhone 模拟器

## 一、 项目背景与技术架构

- **项目基础**：基于 `wonbin-phone` 复刻的纯前端 iPhone 模拟器剧情游戏。
- **技术栈**：原生 HTML + CSS + 原生 JavaScript（无框架，无构建工具）。
- **文件架构**：
  - `index.html`：核心入口，包含 `<audio>` 标签，**通过动态 `load()` 函数按顺序加载 JS 模块（已配置动态时间戳防缓存）**。
  - `app.js`：操作系统核心，包含路由（`show`/`openApp`）、图标库（`G`）、全局音频调度（`AudioHub`）、全局通知、电话逻辑等。
  - `home_ui.js`：**重点模块**。完全接管了主屏幕的 `renderHome`，包含大日历、天气组件、以及**动态旋转+切图的超大黑胶唱片机**。
  - `story.js` & `chat_history.js`：数据层。定义角色、剧情树、微信历史记录、备忘录等。
  - 其他 `app_xxx.js`：独立 App 模块（微信、微博、B站、小红书、闲鱼等）。

------

## 二、 🚨 核心踩坑与铁律（新 AI 必读，绝对不要重蹈覆辙）

### 💥 1. 缓存与白屏坑（极其重要）

- **手机浏览器顽固缓存**：微信/安卓自带浏览器会死死缓存 `index.html` 和 JS 文件，导致你更新了代码，用户还是看旧版。
  - **解决**：`index.html` 的 `<head>` 中必须包含防缓存 `<meta>` 标签；且加载 JS 的 `load()` 函数中必须加上时间戳：`s.src = src + '?v=' + new Date().getTime();`。
- **域名锁白屏**：如果访问的网址不在 `obfuscate.js` 的 `domainLock` 白名单里，浏览器会直接白屏（跳转为 `about:blank`）。
- **`debugProtection` 杀进程**：混淆代码中的 `debugProtection: true` 会导致部分手机浏览器崩溃白屏。**建议设为 `false`**，目前的防盗主要靠 `domainLock` 足够了。

### 💿 2. 黑胶唱片旋转与切图坑

- **DOM刷新打断动画**：当收到微信消息、系统重绘时，如果用纯 CSS `animation` 旋转，会导致唱片瞬间归零重置。
  - **解决**：现在的 `home_ui.js` 中，**坚决不能用 CSS 动画**。已改用 **JS 全局定时器 (`requestAnimationFrame`)** 后台实时计算角度，并通过行内 `transform: rotate(xx deg)` 赋值。配合双层 DOM（外层自转，内层 `background-image` 换图），实现了无感刷新、永不中断。
- **切图逻辑**：用户要求**一首歌播完后切图**（监听 `onended`），而不是转一圈切一次。暂停时**不能切图**，从暂停恢复播放时才切下一张。

### 🎵 3. 音频/媒体坑

- **本地 MP3 `duration` 陷阱**：本地音频在手机端读不到 `duration`，**绝对不要用 `setInterval` 做进度条**。音乐播放器已精简为“列表 + 播放/暂停”。
- **BGM 恢复重置坑**：音频打断只能 `pause()`，**绝对不要碰 `currentTime = 0`**，浏览器会自己记住断点。
- **图标未定义崩溃**：新增 SVG 图标时，尽量在模块内部定义变量（如 `SVG_PLAY`），不要过度依赖 `app.js` 全局的 `G` 对象。
- **挂电话卡死**：`closeCallUI` 挂断后必须退回原界面，不能强行打开电话 App。

### ⏪ 4. 路由与返回键坑

- **侧滑误退网页**：在手机上往右滑或者按物理返回键，很容易直接退出网页。
  - **解决**：监听 `popstate`，在主页时需二次确认（2秒内两次）才允许退出；在 App 内则执行 `goBack()` 并重新压栈 `history.pushState`，防止网页退出。

## 三、 当前核心资产

### 1. 全局音频调度 (`AudioHub` in `app.js`)

- **全自动拦截**：只要页面有任何 `<video>` 或 `<audio>` 播放，它会自动暂停 BGM。
- **扩展法则**：未来在微博、B站加视频，**直接写原生 `<video controls autoplay playsinline>` 即可，绝对不要写多余的暂停 BGM 代码**，`AudioHub` 已经在捕获阶段接管了全局。

### 2. 主屏幕布局 (`home_ui.js`)

- **网格系统**：Grid 严格分块，日历占满顶部，下方为 2x2 的天气/唱片机 + 1x1 的 App 图标。
- **App 图标**：强制正方形（`aspect-ratio: 1`）、防挤压，允许角标溢出显示。
- **黑胶唱片**：尺寸巨大、自定义精细 SVG 唱臂，背景为半透明毛玻璃。
- **轮播机制**：`musicImages` 数组支持无限加图，由 `currentMusicImageIdx` 控制。

### 3. 社交分享卡片 (`index.html` 的 `<head>`)

- 已配置 `og:title`、`og:image` 等。**图片必须是完整的 HTTPS 绝对路径**，且图片尺寸最好为正方形（`600x600` 或 `1200x630`）。
- *注意：分享链接后加 `?v=1` 可以强制微信/微博重新抓取，破除旧缓存。*

### 1. 🎨 关于 SVG 与 图标
- **铁律**：项目中**绝对禁止**在业务代码（`app.js`, `views/*.js`）里直接手写长段的 `<svg>...</svg>`。

- **先讲逻辑再动手**：涉及跳转、状态机、复杂交互，先用文字讲清楚基础逻辑，用户点头后再敲代码。
- **防呆设计**：所有新函数必须带 `typeof xxx !== 'undefined'` 或 `|| {}` 兜底，防止白屏。

### 2. 🧭 全局返回键系统（最新重构，极重要）

不要再让用户在业务代码里手写一大坨返回键代码了！
`app.js` 的 `show()` 函数内已经实现了**全自动返回键注入**：

- **规则**：一级界面（`ROOT_VIEWS` 白名单）**不注入**；二级界面如果**没有** `.nav` 或 `.wx-chat-h` 容器，且**没有**手写 `onclick="back()"` 相关逻辑，系统会自动在左上角（`top: 45px; left: 10px`）生成一个纯色、无圆圈背景的极简箭头。
- **警告**：不要给非 `.nav` 页面乱加返回键，否则会出现双返回键。如果需要，直接让全局系统自动生成即可。

### 3. 💿 黑胶唱片旋转与切图

- **禁止使用 CSS 动画**，必须用 `home_ui.js` 里的 `requestAnimationFrame` 实时计算角度。
- 切图监听 `onended`，用两层 `<img>` 交叉淡入淡出。暂停时不切图。
- 点击播放/暂停时，必须加 `window.isVinylBusy` 锁，防止消息重绘打断动画。

### 4. 🎵 音频与媒体

- `core/audio.js` 已经全局接管了 `<video>` 和 `<audio>` 的播放，任何视频/音频播放会自动暂停 BGM。直接写原生标签即可，**绝对不要手写暂停 BGM 的代码**。
- BGM 被打断只能 `pause()`，**绝对不能**碰 `currentTime = 0`。

## 三、 💡 微信朋友圈逻辑（目前最复杂的模块）

### 1. 数据与路由隔离

- 数据源 `MOCK_MOMENTS_DATA` 必须以角色名作为 Key，不同人拥有不同的 `cover`、`posts`。

- 路由来源严格区分：`_momentDetailFrom`（详情页来源）、`_profileFrom`（资料页来源）、`_momentsUserFrom`（个人相册来源），在 `back()` 函数中精准拦截并 `pop` 回到正确的页面。

- **左侧头像固定**，右侧内容用 `flex: 1` 包裹。名字、文案、图片、日期、灰底框的**左边缘必须绝对垂直对齐**。
- 灰底框（点赞评论）的结构：
  - 第一列固定 `52px` 宽（刚好够放头像和留白）。
  - 点赞的爱心、评论的气泡图标，只在第一列居中/居左显示。
  - 第二列放头像（如 `24px` 或 `32px`），保证评论头像绝对垂直对齐在点赞头像下方。
- 只有**第一条**评论显示气泡 SVG，后续评论用空 `<div>` 占位保持对齐。
- 空状态：不要写“暂无朋友圈”，直接画一条 80px 的灰色虚线和圆点。

## 📂 二、 各模块数据填充模板（照此格式无脑填）

### 1. 微信聊天记录 (`data/chat_history.js`)

**作用**：定义和每个角色的历史聊天记录。
**格式**：`[内容, 'me'/'them'/'sys', '时间']`，必须包含日期分隔线 `[日期, 'date']`。

javascript

```
window.CHAT_HISTORY = {
  '穆祉丞': [
    ['11月12日', 'date'],
    ['今天排练结束得好晚。', 'them', '下午 10:00'],
    ['辛苦了，早点休息。', 'me', '下午 10:05'],
    
    // 👇 特殊消息格式支持（直接复制替换路径即可）：
    ['[图片] ./data/chat/1.jpg', 'them', '下午 10:07'],
    ['[表情] ./data/chat/emoji.png', 'them', '下午 10:08'],
    ['[语音] 5|./data/chat/boli.mp3|今天练舞好累呀', 'them', '下午 10:10'], // 秒数|音频路径|转文字内容

    ['"穆祉丞"撤回了一条消息', 'sys', '下午 10:15'] // sys为系统提示
  ]
};
```
